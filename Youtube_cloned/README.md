# 🎥 YouTube Clone

This project is a **static clone of the YouTube website**, built as part of my journey while completing a **Front-End Web Development course**. The primary goal was to sharpen my skills in **HTML and CSS** by recreating the layout, navigation, and design of YouTube.

---

## 🚀 Purpose of the Project

- 🎯 Practical application of front-end development concepts
- 🎯 Learn how to structure web pages using semantic HTML
- 🎯 Improve CSS skills by replicating a professional, real-world layout
- 🎯 Understand responsive design principles

---

## 📜 Features

- ✅ YouTube homepage layout recreation
- ✅ Navigation sidebar
- ✅ Video thumbnails with titles and channel info
- ✅ Responsive design for desktop and basic mobile layouts
- ✅ Hover effects and clickable-style elements *(non-functional links)*

> ⚠️ **Note:** This is a front-end static project. It does not include JavaScript functionality, video playback, search, or real backend integration.

---

## 🛠️ Built With

- **HTML5** – Structure and content  
- **CSS3** – Styling, layout, responsiveness
